# Loyalty Customer Behavior Analysis

## Business Problem
Loyalty programs generate large volumes of transactional data, 
but most of it goes underused. This project applies RFM segmentation 
and churn analysis to identify behavioral patterns that drive 
retention decisions.

The central questions:
- Which customers are silently churning despite appearing active?
- What behavioral signals differentiate high-value from at-risk customers?

## Dataset
[E-Commerce Data – UCI ML Repository via Kaggle](https://www.kaggle.com/datasets/carrie1/ecommerce-data)

Transactional data from a UK-based online retailer (2010–2011).
~500k rows | Customer ID, invoice date, product, quantity, unit price.

## Planned Approach
1. Exploratory Data Analysis (EDA)
2. RFM Segmentation
3. Churn Definition & Analysis
4. Visualization & Executive Summary
